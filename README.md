# vehicle-service-records-api
A lightweight guide to manage digital vehicle service records, garage job cards, and maintenance history.

We originally built the core of this API to help independent mechanics digitize their workshops, and we are open-sourcing the foundational CRUD operations and PostgreSQL schema for the developer community building in the auto-tech space.

## 🚀 Features
* Standardized RESTful endpoints for vehicle and owner data.
* PostgreSQL schema tailored for job cards and service history.
* Built-in input validation for repair estimates and odometer readings.
